# ChainGo - Decentralized Donation Platform

## Description

ChainGo is a web application designed to facilitate transparent and efficient donations to NGOs for specific projects. It leverages blockchain technology (Sepolia testnet) for donation processing and features distinct dashboards for different user roles: Donors, NGOs, and Administrators.

The platform allows NGOs to register, create projects with funding goals and milestones, and manage their profiles. Donors can explore these projects, connect their MetaMask wallets, and donate Sepolia ETH directly via a smart contract. The smart contract automatically distributes a portion of the donation to the NGO and holds the rest in escrow, releasing it based on admin-verified milestone completion. Administrators oversee NGO verification and milestone approvals.

## Features

* **User Roles:** Separate interfaces and functionalities for Donors, NGOs, and Admins.
* **Authentication:**
    * Email/Password signup and signin for Donors and NGOs.
    * MetaMask wallet connection for signup (optional for Donor/NGO) and signin.
    * Dedicated dummy login for Admin (for demo purposes).
* **NGO Verification:**
    * Mandatory document upload during NGO signup.
    * Admin dashboard for viewing pending NGOs and approving/rejecting applications.
* **Project Management (NGO):**
    * Create projects with name, description, funding goal (in ETH), and milestones.
    * View created projects.
    * Update project milestones to 'completed' status.
    * Resubmit rejected milestones for verification.
    * Edit NGO profile (name, description, logo).
* **Donation & Exploration (Donor):**
    * Explore active projects listed by verified NGOs.
    * View project details, funding progress (ETH & placeholder USD), and NGO information.
    * Donate Sepolia ETH to projects via MetaMask integration.
    * View profile and basic donation summary (placeholder values).
* **Milestone Verification (Admin):**
    * Dashboard view of project milestones marked as 'completed' by NGOs.
    * Approve or reject milestones (rejection includes optional notes).
    * Approval triggers the release of corresponding escrowed funds from the smart contract.
* **Smart Contract Integration:**
    * Handles donation splitting (60% direct, 40% escrowed for milestones).
    * Manages milestone fund release triggered by the admin backend.
* **UI:**
    * Modern UI built with Tailwind CSS and shadcn/ui.
    * Dark mode support with theme toggle.
    * Responsive design with separate desktop/mobile navigation.

## Tech Stack

* **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS, shadcn/ui, Ethers.js, next-themes
* **Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT (jsonwebtoken), bcryptjs, Multer, Ethers.js, dotenv, cors
* **Web3:** Solidity, OpenZeppelin Contracts, Thirdweb (for deployment), Sepolia Testnet
* **Database:** MongoDB (using MongoDB Atlas or local instance)

## Setup & Installation

1.  **Clone the Repository:**
    ```bash
    git clone <your-repository-url>
    cd <your-repository-name>
    ```

2.  **Backend Setup:**
    * Navigate to the backend directory: `cd backend`
    * Install dependencies: `npm install`
    * Create a `.env` file in the `backend` directory (see Environment Variables section below).
    * Fill in the required environment variables in `.env`.
    * Create the `uploads` directory: `mkdir uploads`

3.  **Frontend Setup:**
    * Navigate to the client directory: `cd ../client`
    * Install dependencies: `npm install`
    * Create a `.env.local` file in the `client` directory (see Environment Variables section below).
    * Fill in the required environment variables in `.env.local`.
    * Add shadcn/ui components if not already present (check `components/ui`):
        ```bash
        npx shadcn-ui@latest add button card input label toast sonner dropdown-menu sheet navigation-menu badge progress textarea dialog alert-dialog
        ```

4.  **Web3 Setup (Contract Deployment):**
    * Navigate to the web3 project directory (e.g., `cd ../web3/chaingo-contracts` if you used the guide).
    * Install dependencies: `npm install` (this should include `@openzeppelin/contracts`).
    * Ensure your contract `DonationContract.sol` is in the `contracts` folder.
    * Create a `.env` file in this directory for deployment keys (see Thirdweb guide/Hardhat config).
    * Compile the contract: `npx thirdweb compile` (or `npx hardhat compile`).
    * Deploy using Thirdweb CLI (ensure you have Sepolia ETH in your deployer wallet):
        ```bash
        npx thirdweb deploy -k YOUR_THIRDWEB_SECRET_KEY
        ```
    * Copy the deployed contract address.
    * Update the contract address in `backend/.env` and `client/.env.local`.
    * Copy the generated ABI from the artifacts (e.g., `artifacts/contracts/DonationContract.sol/DonationContract.json`) and paste it into the `contractAbi` variables in `backend/controllers/projectController.js`, `backend/controllers/adminController.js`, and `client/app/donor/explore/page.tsx`.
